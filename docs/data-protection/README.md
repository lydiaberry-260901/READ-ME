# Data protection documents (drafts)

**Status: drafts for review by a solicitor or data protection adviser before use.** They were written to match how the Moca CRM actually works, as built. They are not legal advice.

Anything in [square brackets] must be filled in or confirmed by Moca. Nothing has been assumed about Moca's registration details, suppliers' terms or contracts.

| Document | For |
| --- | --- |
| [Privacy notice for business contacts](01-privacy-notice.md) | Publishing on moca.energy and linking from every first email |
| [Legitimate interests assessment](02-legitimate-interests-assessment.md) | The written reasoning for business to business prospecting |
| [Retention schedule](03-retention-schedule.md) | How long each kind of data is kept |
| [Procedure for requests about data](04-rights-requests-procedure.md) | Handling requests to see, correct, delete, limit, object or receive a copy |
| [Data breach procedure](05-breach-procedure.md) | What to do when personal data goes wrong |
| [Data protection impact assessment](06-dpia.md) | The risk review, including call transcripts and AI use |
| [Supplier checklist and processing agreements](07-suppliers.md) | Checking each supplier and its data processing agreement |
| [Call recording notice and script](08-call-recording.md) | Telling people a call is recorded |
| [Staff guidance](09-staff-guidance.md) | Notes, opt outs and the do not call registers |

The CRM's Privacy centre holds the live versions of several of these: the legitimate interests assessment, the record of what is held, the supplier register, the go live checklist, and the request and breach trackers. Keep the two in step when either changes.
